# dbkeel

dbkeel 是面向 Python 异步应用的轻量级关系型数据库基础设施库，旨在统一数据库的常用操作，并通过可扩展的驱动接入不同数据库。

可独立用于 Web 服务、后台任务和异步脚本，不依赖 FastAPI 等应用框架。

## 核心能力

项目围绕以下能力设计：

- **连接管理**：管理连接与连接池的生命周期，统一连接的获取与释放。
- **SQL 执行**：统一执行、参数绑定和结果读取的使用方式。
- **事务管理**：统一事务的提交与回滚，保留各数据库的能力与限制。
- **SQL 迁移**：统一迁移发现、版本记录和执行流程。

## 数据库扩展

核心层定义通用接口，驱动负责适配具体数据库与底层 Python 驱动的差异。新增关系型数据库支持通过扩展驱动实现，数据库专属配置与能力由驱动提供。

使用者针对目标数据库编写原生 SQL 和迁移脚本。dbkeel 统一使用方式，不转换 SQL 方言，也不保证同一份 SQL 可跨数据库运行。
