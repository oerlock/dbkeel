### 安装与入口

Typer 放在 `cli` 可选依赖中。仅使用 Python API 时无需安装或导入 Typer。

```bash
uv sync --extra cli
uv run --extra cli dbkeel --help
uv run --extra cli python -m dbkeel --help
```

`dbkeel` 与 `python -m dbkeel` 使用相同入口和行为。
缺少 CLI 依赖时，向标准错误输出安装提示，以退出码 1 结束。
PostgreSQL 驱动独立放在 `postgres` 可选依赖中；查看帮助和版本不加载驱动、不读取数据库配置、不连接数据库。

### 帮助与版本

| 调用 | 行为 | 退出码 |
| --- | --- | --- |
| `dbkeel --help` | 显示帮助 | 0 |
| `dbkeel --version` | 输出 `dbkeel <版本号>` | 0 |
| `dbkeel` | 显示帮助，提示选择操作 | 2 |
| 未知命令、未知选项或参数错误 | 显示错误与用法提示 | 2 |

版本号读取已安装包的元数据，不在 CLI 中重复维护。
命令名和选项名使用小写英文，多个单词使用连字符；帮助和错误提示初期统一使用英文。
保留 Typer 提供的 shell 补全选项。

### 输出与失败处理

- 命令结果、显式请求的帮助和版本写入标准输出。
- 参数错误、执行失败和依赖安装提示写入标准错误。
- 执行成功返回 0；预期的操作失败返回 1；命令用法错误返回 2。
- 预期错误提供简短说明，不展示堆栈；未预期的编程错误保留异常信息，不统一吞掉。

具体数据库错误的分类与展示随对应功能设计。本次不增加 `--debug`、日志级别或 JSON 输出选项。

### 职责与扩展

CLI 负责参数解析、调用库功能、展示结果和退出码；业务逻辑放在库中，供 Python API 与 CLI 共用。
初期使用单个 `cli.py`，按需拆分，不预建空命令组。

后续异步操作由同步命令函数通过 `asyncio.run()` 调用。
连接与连接池在同一次异步调用中创建和释放，避免跨事件循环复用。
迁移命令、连接配置和资源生命周期的具体接口另行设计后实现。
